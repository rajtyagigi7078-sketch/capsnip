# Bundled fonts

Capsnip bundles the open-source families used by its standard caption presets so captions render consistently without relying on internet fonts. The accompanying `OFL` folder contains a copy of the Open Font License for each family.

Font source directory: [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl). Families included: Bebas Neue, Playfair Display, Inter, Roboto, Montserrat, Geist, Poppins, Pacifico, Caveat, Architects Daughter, Quicksand, Nunito, Merriweather, Cinzel, and DM Sans.

Additional typography families requested from the handwritten design notes are bundled under `typography/`, each with its source license: Barrio, Rock Salt, Monoton, Plaster, Silkscreen, Moo Lah Lah, Limelight, Vina Sans, Aladin, Barriecito, Bodoni Moda, Righteous, Anton, Bowlby One SC, Aldrich, Oswald, Mouse Memoirs, Special Elite, Bubblegum Sans, Viga, Boldonse, League Gothic, Freeman, and Over the Rainbow. Rock Salt and Special Elite use Apache-licensed source packages; other added families include their OFL files.
